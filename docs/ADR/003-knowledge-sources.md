# ADR-003：一期切片调整与知识源使用许可

- **状态**：Accepted
- **日期**：2026-05-16
- **决策者**：项目作者（PM）
- **相关章节**：PRD §0 范围、§10 内容与知识源、§13 范围与里程碑、§14.3 ADR 索引
- **取代**：PRD v0 §0 范围中"demo 切片：佛教造像 × 上海博物馆东馆"的工作假设

## 背景

PRD v0 §10.1 给出了"一手 / 二手 / 显式禁用"的方向性分级，但未做单馆可行性核查；§14.3 也预留了 ADR-003「知识源使用许可」的占位。同时 PM 考虑把一期 demo 切片从"上博东馆 × 佛造像"调整为"山西博物院 × 北朝/北齐佛造像"，因此触发一次面向具体馆/品类的数据源可行性调研（2026-05-16 完成）。

调研三条关键事实：

1. **国内大陆没有任何一家博物馆达到 Met / V&A / Smithsonian 的开放水平**——既无公开 REST API，也无 CC0 图像声明。规模最大的故宫数字文物库（约 186 万件基础信息、10 万+件高清）和敦煌"开放素材库"（机制最先进、已上链授权）也都各有边界。
2. **山西博物院本身的开放度低于上博**——无开放 API、无 CC0、高清图像未对公众开放；学术抓手集中在馆主办的《文物季刊》（CN 14-1406/K），但全文走 CNKI 付费墙。若一期切片定为"山博单馆"，RAG 的图像层会显著吃紧。
3. **「天龙山数字复原」是山西特有的强加分项**——芝加哥大学东亚艺术中心 × 太原理工大学 × 天龙山石窟所自 2013 年起合作，扫描散落于亚欧 9 国的百余件佛首/造像，数字复原 11 个洞窟，2020 年入选文旅部典型案例，网站 `tls.uchicago.edu` 中英双语公开。

合规层面，立体文物的高清摄影作品在国内司法实践中受著作权保护（参见龙门夜景案、故宫全景案）；学术论文的"短引用 + 标注来源 + 反向链接"在《著作权法》第 24 条框架内可行，**全文向量化目前无明确豁免**，商业 RAG 不建议。

## 候选方案

| 选项 | 切片定义 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 上博东馆 × 佛造像**（PRD v0 原案） | 单馆 | 与 §7 一日剧本贴合、上博学术 PR 资源丰富 | 上博无开放 API、无 CC0；佛造像高清图同样靠灰路径 |
| **B. 山博 × 佛造像**（单馆） | 单馆 | 北朝藏品密度（佛风遗韵展）、本地学术资源 | 山博开放度低于上博、demo 数据层更吃紧 |
| **C. 北齐佛造像 × 跨馆**（山博 / 青州博物馆 / 邺城遗址博物馆 / 河北博物院） | 跨馆品类 | 学术密度最高、可呈现学派之争 | 现场锚点分散、demo 难讲清"在哪个馆用" |
| **D. 天龙山数字回归 × 山博锚点** | 主题策展 | 数字回归叙事天然带"承认争议+跨馆"基因；芝大项目授权机制相对清晰；与 §6 同行爱好者人格契合 | 天龙山实物大头在海外，山博常设展密度有限；3D 数据具体下载条款需邮件申请 |

## 决策

**选择 D。一期切片重新定义为「天龙山：从晋阳到世界——北朝佛造像的流散与数字回归」，以山西博物院"佛风遗韵"常设展为现场锚点，配套以下知识源组合：**

| 层 | 主源 | 角色 | 许可路径 |
| --- | --- | --- | --- |
| 3D / 复原图像 | 芝大天龙山项目 (`tls.uchicago.edu`) | demo 核心视觉、流散叙事载体 | 邮件申请明示授权；未授权前仅链接外引 |
| 壁画 / 纹样比对 | 数字敦煌·开放素材库 (`ip.e-dunhuang.com`) | 北朝纹样、佛传图像对照源 | 个人欣赏与学术研究免费、商用按页定价（300–800 元/张），机制最清晰 |
| 学术内容（半 OA） | 故宫院刊 PDF 直链（`dpm.org.cn/Uploads/File/`） | 论文级解读主源 | "标题+摘要+短引用+URL" 四件套入库，不全文向量化 |
| 学术内容（付费墙） | CNKI 上的《文物季刊》《文物》《考古》《敦煌研究》《艺术史研究》等 | 立场对照、争议呈现 | 短引用+反向链接；不缓存全文；不替代用户自行获取 |
| 流散文物著录 | 中央美院"破碎与聚合"特展（2016）资料 + 嘉德/苏富比/佳士得拍卖图录 | 流散件的存佚补全 | 拍卖图录按版权方条款，仅作旁证 |
| 现场触发 | 山博"佛风遗韵"常设展（含娄睿墓、徐显秀墓相关展品） | 锚定用户物理位置、唤起对话 | 低清示意图 + 文字描述；高清图依赖用户现场自拍（避开版权） |

**显式禁用（沿用 PRD §10.1）**：百度百科、维基百科个别条目（除非有明确学术参考）、自媒体二创、小红书 / 抖音 KOL 内容。

## 理由

1. **绕开"单馆开放度不足"的天花板**：山博从"全部数据源"降级为"现场触发点"，让一期切片在数据层不必依赖任何单一馆的 API/CC0。
2. **叙事完美命中产品基因**：天龙山造像在不同国家、不同博物馆的流散与数字复原，本身就是"承认争议、多家观点、跨次记忆"的天然教材——与 §6 的同行爱好者人格、§7 T5 的跨次记忆 wow moment、§10.3 的学界争议显式标注都自洽。
3. **每个源的版权机制都清晰**：芝大（学术合作授权）、敦煌（已上链、明码标价）、dpm.org.cn（半 OA）、CNKI（短引用+链接）、拍卖图录（版权方条款）——五条路径互不依赖，任一条出问题都不会让 demo 断粮。
4. **demo 的"现场感"仍然可建立**：山博"佛风遗韵"展厅是可被实地走访的物理空间，§7 一日剧本里 T1（蓝牙信标）、T2（你怎么看）、T8（环境噪声）、T13（今日记忆卡）等触点都不需要为切片切换而重写。

## 反幻觉与合规约束（叠加在 PRD §10.3 之上）

补充以下三条具体约束，覆盖本 ADR 选定的源组合：

1. **学术内容入库格式**：仅入库"标题 + 作者 + 出处 + 发表年 + 摘要 + 不超过 100 字短引用 + URL"七字段；**不存全文、不向量化全文**。
2. **图像入库分层**：
   - 芝大 3D / 敦煌素材：未明示授权前**仅入元数据与缩略图**（≤512px 长边），用户点开时跳转源站。
   - 山博现场展品：仅入低清示意图（≤1024px 长边）+ 文字描述；产品默认依赖用户现场拍摄。
3. **"我倾向"门槛**：当 AI 输出涉及断代 / 工坊归属 / 风格归类时，必须能引用到至少 1 篇 CNKI 或 dpm.org.cn 论文；命中 ≥ 2 篇且结论相左时强制走 §7 T7 的"观点对照层"。

## 与 PRD 的同步项（v1 写作时落实）

## 后果与风险

- **后果**：一期 demo 需要在「数字复原叙事」与「现场展厅触发」之间稳定切换；§7 剧本的部分具体物件可能要为山博常设展重写。
- **后果**:Figma 阶段需要新增「跨馆/跨地理的物件对照层」（如某件天龙山佛首的现位置：芝大 / 太原数字复原 / 山博相关同期件），可能与既有"观点对照层"合并。
- **风险一**：芝大天龙山项目的 3D 数据具体下载/授权条款未明示，邮件申请可能拿到的是"展示用低分辨率"而非"研究用高分辨率"。若拿不到合适授权，需降级为"链接外引 + 自摄/媒体公开图替代"。
- **风险二**：山博"佛风遗韵"常设展若改陈、闭展或调整位置，现场锚点会失效。需要在 v1 前实地核查一次展厅状态。
- **风险三**：CNKI 短引用的"合理使用"边界在商业产品上仍有灰度。本项目作为 side project 风险可控；若未来商业化需重做合规评估。
- **未来重审条件**：(1) 中国大陆任一头部博物馆推出真正的 CC0 + 公开 API（如"中国文物云"落地）；(2) 山博推出官方开放数据接口；(3) 天龙山项目的 3D 数据公开授权条款落地；(4) 产品试图扩展到"非北朝"或"非山西"地理时。
