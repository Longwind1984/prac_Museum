> 评审对象：[`docs/PRD.md`](./PRD.md)「一起看」v0
> 评审日期：2026-05-17
> 评审团：5 角色独立 review + 主席综合 summary

## 角色 1 · 资深 AI 产品经理（10 年硅谷 + 国内大厂）

**✅ 保留**

- **§1 PR-FAQ + §1.3 模拟 FAQ**：把 PR-FAQ 倒置叙事用在 AI 原生 side project，是当下作品集里少见的格式自觉。尤其 1.3 Q1「为什么不是 ChatGPT」直接把对手摆上桌、用「五条全反」收口，比 90% 候选人含糊的"我们更专"高出一个档次。
- **§9 Reject List 与 §11.2 反指标**：作品集里 reject list 比 feature list 显功力，这条 PM 自己也写出来了，且反指标里"AI 主动开口次数 / 用户主动开口次数 ≤ 0.5"是真把哲学转成了可审计 KPI——这是 senior PM 才有的肌肉。

**❌ 重写**

- **§6.4 人格的工程化（待 v1 补全）**：v0 最薄弱的一节，只列了"≤80 字、禁词检测"两个机制。作品集里"AI 人格"是核心叙事点，工程化反而最该露肌肉。需补：人格在 system prompt 里的具体结构、对话状态机里 6 条话术准则的 enforcement 触点、人格回归（regression）测试集长什么样。
- **§13.3 时间预算 4–6 周**：作品集 PRD 里写"4–6 周完成 PRD + Figma 全套"既无对外承诺意义，又给 reviewer 留下"作者在赶工"的负面信号。删掉，或换成"分阶段产出节奏"的内部 plan。

**⚠️ 盲点**

整份 PRD 把"AI PM 思维显性化"做得很足，但**没有任何一处展示"我作为 PM 怎么和工程 / 设计 / 数据团队协作"**——没有 RACI、没有跨职能 trade-off 记录、没有"我曾经被工程师反驳过"的痕迹。一线大厂 reviewer 看 PM 作品集第二轮重点恰恰是这个。可考虑在 §14 加一条"假想协作记录"或"假想 design review 纪要"。

## 角色 2 · 文博 / 艺术史背景专家

**✅ 保留**

- **§7.2 T3「秀骨清像」+ T5「曹衣出水」**：术语用得准、放在对的语境里（北魏晚期瘦削风格 / 北齐造像饱满风格脉络），不是堆砌名词。T7 把"龙门石窟某个特定工坊 vs 泛盛唐"作为 AI 立场示例，这种"抗拒空泛断代、下钻到工坊"的姿态，是真懂行的人才说得出的话，能立住"同行资深爱好者"的人设。
- **§10.1 数据源分级与 §10.3 反幻觉策略**：把百度百科 / 自媒体二创 / KOL 内容显式禁用，把馆方标签 vs AI 解读分层呈现，是文博内容产品里少见的内容洁癖。金维诺、罗世平的引用方向（§14.4）也对。

**❌ 重写**

- **§7.2 T9「上博的标签写北齐，我不太敢肯定，它的衣纹处理更像北周」**：这是高风险段落。北齐 / 北周衣纹差异在学界确实有讨论，但让 AI 公开质疑馆方断代——一旦 AI 引用的论文不到位，会被业内人当面打脸，且伤害的是产品的可信度而非馆方。建议改写为"这件断代学界有不同看法，要不要我把那篇论文留给你"，把"反对馆方"降级为"补充学界视角"。
- **§7.2 T7 观点对照层的"学界争议"列**：写"2010 年和 2018 年两份论文意见相左"过于轻飘——业内人会立刻追问是哪两篇。建议在 PRD 阶段就给出 1-2 个真实可引用的范例（佛造像工坊归属研究里确实有这种争议案例），否则会被认为是"PM 没真读过论文"。

**⚠️ 盲点**

PRD 反复强调"佛教造像 demo 切片"，但**完全没提及宗教 / 信仰语境的处理边界**。佛造像不是一般艺术品——AI 在和用户讨论时，遇到信众用户（合掌、礼拜）怎么应对？AI 是否会无意中流露"把信仰对象作为艺术品评赏"的视角？这在国内文博实际场景里是真实存在的伦理盲区，作品集里如果展示对这层敏感性的觉察，会显著提高深度。

## 角色 3 · 资深产品设计师 / UX

**✅ 保留**

- **§8.2 克制式屏幕设计六条**：每一条都给了反例，这是设计 spec 而不是宣言。第 5 条「合上手机」按钮和第 6 条「耳机即转语音」尤其漂亮——前者是反 App 设计、后者是形态切换的明确规则，Figma 阶段可直接画出。
- **§7.2 T6「合上手机看 30 秒」**：交互节奏写得有画面感（点按 → 全黑 + 倒计时小数字 → 柔光亮起 → 反问），这是从交互节拍角度而非功能列表角度写 PRD，少见。

**❌ 重写**

- **§7.2 T2「锁屏上极轻地点亮一个小圆点，屏幕不亮起」**：技术上 iOS / Android 锁屏 API 不允许这种程度的局部唤起，整段交互逻辑在真实手机平台上做不出来。Figma 可以画，但 demo 阶段 reviewer 一旦用 iOS 设计师视角追问，会立刻穿帮。需要在 §8 或 §12 加一段"已知平台约束 + 在 demo 阶段的妥协方案"。
- **§7.2 T7 观点对照层（四列）**：四列表格在手机竖屏上视觉上不成立——单屏宽度只够 2 列舒适阅读。PRD 写"四列对照"，Figma 阶段一定会卡住，得改成"卡片堆叠 / 切换 tab / 横向滑动"中的一种，需要在 PRD 里就决定。

**⚠️ 盲点**

14 个触点跨 2 小时 + 1 个月，**信息架构远比想象的复杂**——状态机里至少要管理：当前展厅、停留时长、是否戴耳机、长程承诺队列、跨次记忆触发条件、疲倦窗口。PRD §14.1 只列了 14 条功能，但没有任何一处给出"状态机草图"或"模式切换矩阵"。从 PRD 到 Figma 之间还差一份**状态/模式表**，否则 Figma 会陷入"每屏单独画、屏间逻辑对不上"的泥潭。

## 角色 4 · 科技投资人 / 战略 reviewer

**✅ 保留**

- **§5.2 vs 通用 AI 的 5 条护城河表**：是整份 PRD 战略密度最高的一段。"领域深度 / 空间时间感 / 跨次记忆 / 策展人格 / 克制"五条不是同一层级，但作为护城河组合是有逻辑闭环的——前两条是数据壁垒、第三条是切换成本、后两条是品牌资产。
- **§2.3 为什么是现在**：把多模态成熟、RAG 工程化、馆方数据开放三件事放一起，给出了清晰的 timing 判断，且明确指出"没有一个现存产品把这三个条件用来做范式切换"——这是 VC pitch 里 "why now + why nobody" 的标准回答结构。

**❌ 重写**

- **§5.2 五条护城河的可持续性**：在 18 个月视角下，**只有"跨次记忆"是真正的长期护城河**，其余四条都会被通用 AI 抹平——领域深度（GPT-6 + 馆方 MCP）、空间时间感（Apple Intelligence + 位置）、策展人格（system prompt 可复制）、克制（UX 选择不是壁垒）。PRD 把五条平铺，战略上是过度自信。需要在 §5.2 或 §12.4 里诚实排序"哪条 18 个月内会被磨平、哪条会留下"，并解释为什么"跨次记忆 + 用户私有数据"是唯一真正的飞轮。
- **§12.4 商业 / 持续性风险**：仅一段，过于轻描淡写。即便是 side project，作品集 reviewer 也会问"如果你做这事 3 年，靠什么活下去"——B2B 授权和 C 端订阅都需要在 §1.3 FAQ 或 §12.4 里至少给一个 napkin math（馆数 × 单馆授权费 / 用户数 × ARPU），否则"不商业化"会被误读为"没想清楚"。

**⚠️ 盲点**

PRD 完全没提**馆方反对的可能性**——一个独立第三方 App 在馆内通过蓝牙信标识别用户位置、并公开质疑馆方断代（T9），馆方是否会发律师函或撤场？Smartify 之所以走"被馆方授权"路线，本质是回避了这层冲突。作品集 PRD 可以选择"独立第三方"的姿态，但需要在 §12.2 著作权与馆方关系里**显式承认这层博弈**，否则战略上是天真的。

## 角色 5 · 目标用户代理（模拟林知白本人）

**✅ 保留**

- **§7.2 T5 跨次记忆首次触发**：「你三年前在国博看那件曹衣出水的时候，停了 11 分钟。」——我读到这段是真的起鸡皮疙瘩了。"11 分钟"这种具体到分钟的颗粒度，是我作为用户判断"这玩意儿真懂我 / 还是在演懂我"的分水岭。这一段如果真做出来，我会留下。
- **§7.2 T6「合上手机看 30 秒」+ T13 没有分享按钮**：作为一个工作日被红点淹没的设计师，"App 推我把手机合上"这件事本身就是一个产品宣言，我愿意为这个宣言留 App。T13 没有分享按钮——这一刀我也喜欢，因为我去博物馆从来不发朋友圈。

**❌ 重写**

- **§7.2 T2「停了 40 秒 → 锁屏点亮小圆点 → 用户扫一眼按下『你怎么看』」**：这段我作为用户会出戏。我站在文物前 40 秒是因为我在看文物，不会一直瞟手机锁屏；而且让我在没看明白的时候就先输出"庄严"这种 emoji，是一种**反向打扰**——AI 用"对等"的名义提前要求我表态，比直接讲解更累。可以改成"用户主动掏出手机时再触发"或"完全靠用户长按一个物理按钮发起"。
- **§7.2 T8 环境噪声触发模式切换**：人多了 App 主动推「要不要切到耳机模式？」——这条对我来说太"贴心"了，反而像 Siri 那种廉价主动。我宁愿 App 一直沉默，让我自己决定戴不戴耳机。这条违反了它自己 §11.2 反指标"AI 主动开口次数 ≤ 用户的一半"。

**⚠️ 盲点**

整份 PRD 假设我是"独自来"的访客（§7.1 明确写「独自」）。但作为 32 岁的我，**实际去博物馆 60% 的时候是和女朋友 / 朋友一起去的**。两个人共看一件文物时，AI 应该说话吗？应该说给谁听？跨次记忆是绑定个人还是共享的？这是 PRD 完全没碰的真实使用场景，但它会决定我是不是真用得起来——独自看博物馆的产品，市场比作者想的小。

## 评审团 Executive Summary（主席综合）

### 总体评级（满分 10）

| 维度 | 评分 | 简评 |
|---|---|---|
| **作品集水准** | 8.5 | PR-FAQ 框架 + reject list + 反指标 + 一日剧本，是同类 side project 里少见的格式自觉与产品哲学密度，已具备"top 10% PM 作品集"的相 |
| **产品深度** | 7.5 | 哲学层与机制层咬合得紧（克制 → 6 条设计约束 → 反指标），但人格工程化、状态机、馆方博弈三处明显薄弱 |
| **落地可行性** | 6.0 | 14 个触点中至少 3 处（T2 锁屏、T7 四列、T8 环境感知）从 PRD 到 Figma / 工程会卡住，需要再下一层细化 |

### 三大共识强项

1. **产品哲学 → 可审计机制的链路完整**：克制 / 立场 / 记忆 / 对等不停在态度宣言，而是分别落到 §8.2 设计 6 条、§11.2 反指标、§7.2 一日剧本里的具体触点。AI PM、设计师、用户代理三角色都点了赞。
2. **跨次记忆的杀手时刻设计成立**：T5「三年前 / 11 分钟 / 曹衣出水」被 PM、文博、用户三角色独立指认为最有冲击力的段落，且战略 reviewer 也确认这是 18 个月内唯一不会被通用 AI 磨平的护城河。
3. **Reject List 的纪律性**：PM 视角、用户视角都看到了同一个事实——"不做什么"比"做什么"更显产品定力，且 reject list 与 §11.2 反指标互为印证，不是装饰性的。

### 三大共识盲点

1. **从 PRD 到 Figma / 工程之间还差一层细化**（设计师、PM、用户三方共识）：状态机、模式切换矩阵、四列对照在手机竖屏上的具体落法、锁屏 API 真实约束——这些在 PRD v0 里都是模糊的，Figma 阶段会卡。
2. **18 个月护城河被高估**（战略 reviewer + PM）：5 条护城河里 4 条会被通用 AI 磨平，PRD 平铺呈现是过度自信，需要诚实排序并把战略叙事压到"跨次记忆 + 用户私有数据飞轮"这单点上。
3. **真实使用场景被过度简化**（用户 + 文博 + 战略三方）：独自看 vs 同伴看、信众语境、馆方关系——三个真实世界的复杂度都被 PRD 回避了，这些不补，作品集的"真实感"打折。

### 进入 v1 前的优先级建议（按优先级排序）

**P0（必须在 v1 改）**

1. **§7.2 中至少 3 个触点的现实性校准**：T2（锁屏 API）、T7（四列竖屏布局）、T9（公开质疑馆方断代降级为补充学界视角）。每处给出一段"已知约束 + 妥协方案"。
2. **新增"状态机草图 / 模式切换矩阵"小节**（建议放 §7.4 或 §14.2）：覆盖展厅 / 停留时长 / 耳机 / 长程承诺队列 / 跨次记忆触发 / 疲倦窗口 6 个状态维度的组合规则。这是 PRD → Figma 之间必经的桥。
3. **§5.2 五条护城河重排 + §12.4 战略叙事收口到"跨次记忆飞轮"**：诚实承认 4 条会被磨平、押注第 5 条，反而显得战略思维成熟。

**P1（v1 应改）**

4. **§6.4 人格工程化补全**：system prompt 结构、6 条话术准则的 enforcement 触点、人格回归测试集——这是作品集里 AI PM 显肌肉的关键章节。
5. **新增"真实使用场景的边界"小节**：同伴共看、信众语境、馆方博弈——每条 1 段，承认存在 + 给 v2 处理方向。这是从"演哲学"转向"真懂用户"的必经一步。

**可选（删 / 缩）**

6. 删除 §13.3「4–6 周时间预算」对外承诺；§14.4 参考文献至少落实 2-3 篇真实可引用论文，否则比留空更伤可信度。

---

**主席结语**：v0 已经具备一份优秀 AI PM 作品集的骨相——产品哲学清晰、机制咬合紧、反指标有纪律。但要从 8 分上探 9 分，必须做的不是再加章节，而是**把现有章节做"诚实"两层**：诚实承认平台约束、诚实排序护城河、诚实面对真实使用场景的复杂度。v1 砍掉一切粉饰，留下骨头，反而更有冲击力。
