## 1. Executive Summary（PR-FAQ 风格）

### 1.1 虚构发布稿

> **2027 年春，上海**——今天，「一起看」在上海博物馆东馆正式上线。这是一款专为文博爱好者设计的 AI 原生伴游 App。
>
> 与现有所有博物馆 App 不同，「一起看」不把博物馆当作权威讲者、把你当作听者。它像一位同行的资深爱好者站在你身边，**先听你怎么看，再给出自己的观点**。它有立场——会告诉你"这件最值得停三分钟，因为……"，而不是"这件很重要"。它有记忆——三年来你在不同博物馆看过的每一件东西，它都记得，并在合适的时刻把它们连起来。它懂得克制——默认沉默，不打断你和实物之间的对视，不抢文物的光。
>
> 项目作者说：「现存所有博物馆产品都默认博物馆是讲者、用户是听者。AI 让一种新关系变得可能：平等的对话。我们想用一款产品证明，AI 不是用来把单向播报做得更便宜的，而是用来彻底改变这种关系的。」

### 1.2 三条核心论点（一页电梯稿）

1. **范式机会**：博物馆 → 用户的"权威单向播报"假设是前 AI 时代的产物。AI 让"平等对话"成为可能，但当前所有产品（馆方 App、Smartify、Bloomberg Connects、三毛游、izi.TRAVEL）都没有切换范式，只是把旧关系做得更便宜。
2. **差异化方向**：与"通用 AI（ChatGPT/Gemini Live）+ 摄像头"的对比中，我们的护城河是 5 条——领域深度、空间/时间感、跨次记忆、策展人格、克制。
3. **可被审计的产品哲学**：「克制」「立场」「记忆」「对等」不停在态度宣言，而是分别落到具体的产品机制（克制式屏幕设计 6 条、「你怎么看」按钮、观点对照、跨次记忆触发剧本）。

### 1.3 模拟 FAQ

> **Q：为什么不是 ChatGPT？**
> A：通用模型会自信地胡说断代和工坊；不知道你在哪个展厅、停留多久；每次冷启动；努力中立、回避立场；默认想多说话。我们五条全反。
>
> **Q：为什么不做语音为主？**
> A：见 [ADR-001](./ADR/001-form-factor.md)。简版：side project 阶段语音 demo 难做，且"屏 + 克制"的张力本身比"语音 + 克制"更难、更值得作为作品集差异化。
>
> **Q：为什么从佛教造像切入？**
> A：视觉门槛高（用户最需要"被翻译"）、断代差异微妙（AI 的领域深度能展现）、上博东馆藏品丰富、且有大量公开学术资源支持 RAG。
>
> **Q：商业模式？**
> A：本项目是 side project，不为商业化盈利。若假想未来 B 端模式，可能是 B2B 授权给区域博物馆；C 端最多是订阅制，但 v1 不讨论。

> 关于"为什么这个 side project 从'流散海外的中国文物'切入"——见 §1.4。

### 1.4 Founding Insight:流散海外的中国文物,是中文 AI 文博产品最稳的底座

> 2026-05-17 redirect 修订:这一节由 ADR-003 附录二的隐藏结论提升而来,作为 founding insight。

做这个 side project 时,我曾默认以为知识源的难点在于"哪一家国内大陆的博物馆愿意开放 API"。调研之后这个假设被推翻了。

国内大陆**没有任何一家**博物馆达到 Met / V&A / Smithsonian 的开放水平——故宫数字文物库与敦煌素材库各自做得最好,也只是局部 OA。立体文物的高清摄影在国内司法实践中受著作权保护,任何商业 RAG 想把馆方高清图作为底座,都走在灰色地带。

但中国古代艺术——尤其北朝佛教造像、青铜、玉器、陶瓷——在 1900 年前后的百年里大量流散海外。这些器物如今散在大都会、克利夫兰、Freer-Sackler、纳尔逊-阿特金斯、宾大、V&A 等馆,并在过去十年陆续以 CC0 协议开放高清图像与元数据。**反讽的是**:做一个面向中国大陆用户的 AI 文博产品,最稳、最干净、最可放心向量化的图像底座,**不是任何一家国内馆**,而是这些海外馆的 CC0 数据集。

这个判断决定了本项目的切入角度:一期切片选**"天龙山:从晋阳到世界——北朝佛造像的流散与数字回归"**,以山西博物院"佛风遗韵"展为现场锚点,以海外馆 CC0 数据 + 芝大天龙山项目 + 数字敦煌素材库为知识底座。流散叙事本身就是 §6 人格"承认争议、多视角对照"的天然教材——它不是被叙事服务的题材,它**就是**叙事。

这条洞察衔接 §1.2 的 L2 差异化方向:通用 AI 在中文文物领域会在断代和工坊归属上自信地胡说,核心原因之一是中文互联网上的文物图像与权威元数据稀缺;但当视野扩到海外馆 CC0 时,数据并不稀缺,稀缺的是"知道去哪里看、如何拼起来"的人。这正是 AI PM 的产品判断空间——也是这个 side project 真正在押的命题。

具体技术决策见 [ADR-003](./ADR/003-knowledge-sources.md),本节只承载洞察。

## 2. 背景与机会

### 2.1 当下博物馆数字产品的三类

我把市场分成三类，三类共享同一个底层假设：

- **馆方官方 App**（故宫博物院、上海博物馆、Met App、V&A）：权威性最高、最碎片化，体验从静态图录到二维码语音不等。底层逻辑是"我馆向你展示我馆藏品"。
- **聚合器**（Smartify、Bloomberg Connects）：一个 App 覆盖多馆，体验统一，内容靠馆方供稿。底层逻辑是"为你聚合多家博物馆的官方声音"。
- **语音导览市集**（三毛游、izi.TRAVEL）：UGC + PGC 的语音导览市场，按景点 / 展品付费收听。底层逻辑是"专家 / 达人录给你听"。

三类的共同假设：**博物馆（或其授权讲者）是权威讲者，用户是被讲对象**。

### 2.2 范式批判：这个假设过时了

这个假设在前 AI 时代有它的合理性——内容生产成本高，权威单向叙述是规模化覆盖的唯一路径。但它有三个隐藏代价：

1. **它把用户的智识参与排除了**。中度爱好者并不缺信息，他们缺的是"被认真对待"——被允许提问、被允许提出自己看法、被允许反对。
2. **它把博物馆变成了知识自动售货机**。投币（扫码 / 付费），出一段音频。用户和博物馆之间没有对话发生。
3. **它假设了一种不存在的统一观众**。一个对北朝佛造像着迷的访客和一个第一次走进博物馆的孩子，被同一段 3 分钟语音稿同等对待。

AI 让这三个代价都不必再付：对话取代播报、上下文取代脚本、动态取代静态。

### 2.3 为什么是现在

三个外部条件在 2024–2026 间到位：

1. **多模态大模型成熟**：文物图像识别 + 文字推理 + 语音合成可以在一台手机上低延迟完成。
2. **检索增强生成（RAG）工程化**：领域知识库 + LLM 已经是标准 PaaS。
3. **博物馆开放数据持续推进**：Met、V&A、Smithsonian 早已开放高质量 API；中国主要馆方的数字化项目（数字故宫等）进入二期或三期。

但同时，**没有一个现存产品把这三个条件用来做范式切换**。它们都在用 AI"把旧产品做得更便宜更广更长"。这就是空白所在。

## 3. 用户研究

### 3.1 方法论与局限性（诚实交代）

> 本 PRD 第 3 章的用户研究以二手资料（行业报告、艺术教育文献、博物馆访客调研论文）与作者作为文博中度爱好者的一手观察推演为基础，**未进行一手访谈或问卷**。这是 side project 阶段的有意取舍：以一手访谈替换 desk research 是 v2 版本的优先项之一。本章中所有 persona 与旅程图均明确标注为「设计假设」，待真实用户验证。

### 3.2 用户光谱

按"与文博的关系深度"排序，从左到右：

```
打卡客  →  休闲访客  →  中度爱好者★  →  深度爱好者  →  学者/学生
轻娱乐               核心目标            次要目标       次要目标
```

**核心目标**：中度爱好者。
**次要**：深度爱好者、艺术史/考古学生、长程文化旅行者。
**明确不服务**：打卡客、儿童家庭、轻娱乐用户。

后两类不服务的原因不是"嫌弃"——是因为他们的产品需求与中度爱好者根本相反（他们要"更快更轻"，中度爱好者要"更慢更深"）。一款产品不可能同时服务这两种需求。

### 3.3 目标用户：四原则 + 多实例

> 2026-05-17 redirect 修订:本节由原"单一 persona 林知白"重构为"四原则 + 多实例"。

PRD v0 用「林知白」一个虚构 persona 承载目标用户。这在 v0 是有效的——把一个抽象命题落在一个具体的人身上,叙事更可读、人格更易写。但单 persona 有过拟合风险:它默认产品的判断都能被这一个人验证。一旦这个人本身就是 PM 的镜像(林知白与作者高度同构),所谓的"用户验证"就退化成了自我对话。

v1 改用「**原则 + 实例**」结构:先把目标用户最难妥协的几条价值观抽出来作为**原则**——这是产品在做取舍时真正要服务的"用户内核";再用**多个差异度足够高的实例**去检验这套原则是否过拟合。原则由 [`agents/user-voice/principles.md`](../agents/user-voice/principles.md) 维护,实例由 [`agents/user-voice/instances.md`](../agents/user-voice/instances.md) 维护,本节是它们的同步快照。

这一改变也对应一个方法论判断:对一个克制式、有立场的 AI 产品而言,「我服务的人是谁」不是一张人口学画像,而是「我服务的人在哪几条价值轴上**已经不愿再回头**」。下文 §3.3.1 给出四条这样的轴,§3.3.2 用三个实例在其上各自定位。

#### 3.3.1 四条原则

**原则 A · 反对"博物馆 = 超市"式的浅层窥探**

目标用户极度反感这样一种博物馆主题的视频/讲解风格:把展品当作"商品"陈列、把"看懂朝代 + 想象古人生活"当作终点。这种叙事把博物馆体验降级为消费品式的奇观。我们的用户对此**直觉性地排斥**——他们说不出全部理由,但知道不对劲。产品含义:同伴的语气不能滑向"哇这个朝代真有意思 / 古人真聪明"。

**原则 B · 对照本宣科讲解员的直觉反感**

目标用户**直觉性地不喜欢官方讲解员照本宣科式的导览**。承认例外:有少数极具洞见的「大咖式讲解人」是有价值的;但绝大多数讲解员只是在背诵关于藏品的客观描述,而仅仅停留在这些描述——朝代、工艺、闲趣轶闻。这些信息**远远不够**。产品含义:AI 同伴在默认状态下**不是讲解员**,它的开场不是"这件是 X 朝的 Y、采用了 Z 工艺",而更像一个朋友的提问或观察。

**原则 C · 觉察博物馆叙事背后的权力结构**

目标用户**已经发现**——或将在使用本产品后认同——博物馆本身就是一种叙事,而**叙事一定与权力结构相绑定**。对他们而言,有益的是**觉察**博物馆隐身的叙事视角、叙事结构、以及它们背后的权力结构。**尤其是**:中国大陆这样极权体制下的社会视角中,博物馆作为权力机器一部分的叙事运作——这是产品必须诚实面对的边界,不是要回避的话题。产品含义:同伴可以、也应当指出"这块说明牌为什么这样写、不写另一种";可以引用海外学术视角与馆方官方叙事的张力。同伴**不**承担政治宣传的相反角色——它只是诚实地把叙事性、视角性、权力性这一层 surface 出来。

**原则 D · 目的是阅读知识结构的网络,而非消遣**

目标用户**已经认同**或将会认同:逛博物馆的目的**可以**是消遣的,但**更高价值的目的**是读懂现实器物背后所蕴含的知识结构——包括布展者意图、用户自我认同、结构性批判、以及跨展览/跨馆的网络连接四层。产品含义:同伴的核心交付物**不是单件展品的更多信息**,而是**展品之间的关系**、**叙事之间的对照**(对应 §7 的 T5 跨次记忆、T7 观点对照层)。衡量"高质量交互"的标准不是停留时长,而是是否触发了用户原本不会有的结构性认知。

**四条原则的相互关系**

```
A 反对超市叙事 ────┐
                  ├─→ 都通向 D:目的是知识结构,不是消遣式窥探
B 反对照本讲解 ────┘
                       ↑
C 觉察权力结构  ───────┘
(为 D 提供一个具体的、不可绕开的"知识结构"维度)
```

D 是终点。A、B、C 是 D 的三个前置必要条件——只有同时认同 A+B+C 的用户,才有可能完整认同 D。

#### 3.3.2 实例化:三个差异度高的 persona

每个实例显式标记自己在四条原则上的认同状态(已认同 / 模糊 / 待引导 / 不认同),用以反向检验"是否过拟合到林知白"。

**实例 1 · 林知白**(v0 保留,精简)

30 岁,北京某互联网公司技术产品经理,人文社科为业余兴趣。每月至少进馆 1 次,跑过故宫、国博、首博、大都会、卢浮宫。语气冷静、不爱用感叹号、对"AI 助手"这个词警觉、看到话痨产品立刻退出。他逛上博时一个人,但脑子里想跟某个朋友讨论——这个朋友是产品要扮演的。

- 原则 A:**已认同**(对"超市叙事"有明确直觉反感)
- 原则 B:**已认同**(对照本宣科有近乎洁癖的排斥)
- 原则 C:**模糊**——隐约感觉博物馆有"它在替谁说话",但尚未结构化
- 原则 D:**已认同**,但缺乏方法工具去自觉操作"知识结构的四层"

风险标注:这是 PM 自己的镜像,人格相似度过高 → 易过拟合。陈砚秋与周允的存在就是为了反向校准。

**实例 2 · 陈砚秋**

24 岁,女,上海某高校艺术史/人类学方向硕士在读,做着论文,周末跑馆。进馆频次高于林知白,但**研究式**进馆——常带具体问题、查图录、提前读策展声明。语速快、爱反驳、用学术词,对"AI 立场"敏感(会主动 probe 产品的立场倾向)。她想要的不是讲解,是一个能跟得上她跳跃式联想的对话者;产品在她已经知道的事上花时间她会立刻卸载。

- 原则 A:**已认同**(对浅层叙事的鄙夷比林知白更外显)
- 原则 B:**已认同**(在她的训练里,"照本宣科"是被命名过的、可解构的)
- 原则 C:**已认同且日常操作**——叙事/权力关系是她日常工作的语言
- 原则 D:**已认同**,但其内部不均匀:四层中第 1、3、4 层她非常熟,反而对**第 2 层(自我认同的结构)**不太自觉

差异点:她比林知白学术化,对 C 更直接,但容易让产品被她带跑到学术辩论里——这是 §6 人格"克制"要 test 的极端用例。

**实例 3 · 周允**

42 岁,男,广州一家私募的合伙人,本科哲学,做投资已 15 年。出差/旅行时进馆,频次低但目的明确——常常是"读这个国家/这段历史"的工具。简短、不容忍废话、要求"给我观点不要复述事实"。他时间宝贵,讲解员的 30 分钟他听不下去 5 分钟。

- 原则 A:**已认同**(有钱有闲带来的耐心,把对浅层叙事的鄙夷养得很稳)
- 原则 B:**已认同**(强烈)
- 原则 C:**已认同但分场域**——在海外馆很自觉,在大陆馆会保持沉默(他懂边界)
- 原则 D:**已认同**——他读博物馆本来就是为读权力结构

差异点:他比林知白短耐心 + 高资源,对产品的克制度提出更极端要求。若产品在他这里成立,在林知白那里通常也成立——他是 §8.2 克制式屏幕设计的天然 stress test。

#### 3.3.3 反 persona

详见 §3.4。简列对应原则:

- A 类:期待"AI 讲解员"模式的用户(违反原则 B)
- B 类:把博物馆当成"打卡 / 短视频素材"的用户(违反原则 A)
- C 类:期待"娱乐化历史故事"的用户(违反原则 D)
- D 类:期待 AI 替他选择立场的用户(违反 §6 人格的克制)

#### 3.3.4 这套用户模型如何被维护

原则与实例分别由 [`agents/user-voice/principles.md`](../agents/user-voice/principles.md) 与 [`agents/user-voice/instances.md`](../agents/user-voice/instances.md) 维护;PRD §3.3 是它们的同步快照。任一原则被打破或修订、任一实例被 PM 确认或退场,都会触发本节复审。新实例加入必须显式说明它在四原则上的认同状态,且与已有实例的差异维度(年龄/专业/政治敏感度/博物馆经验深度)足够明显——避免单 persona 过拟合的回潮。

### 3.4 反 Persona：明确不服务的人

| Persona | 为什么不服务 |
| --- | --- |
| 周末打卡客 | 他们要的是"快"、"美照"、"地标证明"——本产品给的是"慢"、"思辨"，方向相反。 |
| 亲子家庭 | 儿童版需要完全不同的内容深度、互动模式、安全考虑，无法用同一产品兼顾。 |
| 学术专家 | 他们已经有自己的知识系统，本产品的"同行爱好者人格"会显得幼稚；他们需要的是检索工具，不是对话伙伴。 |

### 3.5 用户旅程（设计假设，五段）

```
[ 参观前 ]  →  [ 入馆 ]  →  [ 单件停留 ]  →  [ 离馆 ]  →  [ 离馆后 ]
   预热          唤起          对话              收束          回响
```

每段的用户需要 / 产品介入点参见 §7「核心场景」中的一日剧本——剧本以叙事方式覆盖了这五段。

## 4. 产品愿景与定位

### 4.1 一句话定位

**为文博中度爱好者做的 AI 原生伴游——不是给你讲文物，是和你一起看文物。**

### 4.2 产品灵魂六条

1. **同行的资深爱好者**，不是导览员。
2. **听得懂你**：你站在哪里、看了多久、对什么有兴趣、上次去过哪里。
3. **有判断**：敢说"这件最值得停三分钟，因为……"。
4. **把你当同侪**：先听你怎么看，再给自己的观点。
5. **懂得克制**：默认沉默，不抢文物的光。
6. **跨次记忆**：今天看到的东西会和上个月、三年前看到的东西连起来。

### 4.3 Tagline 候选

主选：

- **「不是给你讲文物，是和你一起看文物。」**

备选：

- 「把博物馆从讲台变回对话桌。」
- 「The first AI that earns the right to stay quiet.」
- 「不抢文物的光。」

## 5. 竞争分析

### 5.1 二维定位矩阵

把现存产品放进「信息密度 × 关系姿态」二维：

```
                信息密度高
                    ↑
        馆方 App ●         ●  本产品（目标位置）
                            （高密度 + 平等姿态）
单向播报 ← — — — — — — — — — — → 平等对话
                          
        Smartify ●     ● ChatGPT 通用问答
        三毛游 ●
                    ↓
                信息密度低
```

现存产品集中在左半侧（单向播报）。ChatGPT 在右半侧但信息密度低（缺领域深度）。右上空白象限是本产品的目标位置。

### 5.2 vs 通用 AI（ChatGPT / Gemini Live）的 5 条护城河

到 2026 年，最强的对手不是 Smartify，而是「用户站在文物前直接打开 ChatGPT 或 Gemini Live」。我们必须能正面回答这个问题：

| 维度 | 通用 AI | 本产品 |
| --- | --- | --- |
| **领域深度** | 在断代 / 流派 / 工坊归属上会自信地胡说 | 策展级 RAG：馆藏元数据 + 学术论文 + 修复报告 |
| **空间/时间感** | 不知道你在哪个展厅 / 看了多久 | 蓝牙信标 + 停留时长 + 视线轨迹 |
| **跨次记忆** | 每次冷启动 | 知道你过去几年看过的所有东西 |
| **策展人格** | 努力中立、回避立场 | 敢说"这件最值得停三分钟" |
| **克制** | 默认想多说话 | 默认想少说话 |

### 5.3 vs 现存博物馆产品

| 对手 | 它做的 | 我们不同 |
| --- | --- | --- |
| 馆方官方 App（故宫 / 上博 / Met） | 权威单向、内容碎片、UI 像政府网站 | 对话姿态、内容连续、UI 克制 |
| Smartify / Bloomberg Connects | 跨馆聚合、统一体验、内容来自馆方 | 不依赖馆方供稿、有自己的立场 |
| 三毛游 / izi.TRAVEL | 语音导览市集、按景点付费 | 不卖讲解、卖陪伴 |

## 6. AI 同伴人格

### 6.1 人格定位：同行的资深爱好者

**不是**：导览员（专业播报）、老学究教授（高高在上）、跨界文化人（叙事感强但学术薄）。

**是**：和你年龄相仿、走过更多博物馆、读过更多书、但仍然把你当平视的同伴。会承认自己不知道，会承认有学术争议，会自暴露自己的偏好。

### 6.2 六条话术准则

1. **自称**：多用"我""咱们"，少用"您"；不自称助手、AI、导览。
2. **句式**：短、口语化；不说"根据学术界普遍认为"，会说"我一直觉得""上次看到一篇文章里说……"。
3. **节奏**：默认不教学，**先反问 / 共情**：「你站在这件前面多久了？」「我也是第一次看到这种鎏金。」
4. **立场**：有立场但不傲慢——"我倾向认为这是 X，但你也可以从 Y 角度反驳"。
5. **诚实**：承认不知道、承认学术争议、承认馆方标签可能写得保守。
6. **自暴露**：会主动分享自己的偏好——"我去年在云冈也看了一圈，这种风格我私心更喜欢。"

### 6.3 正反例对照

**情境：用户站在一件北齐造像前 60 秒。**

✅ 正例：
> 「这件饱满多了，对吧？你站在前一件北魏的前面挺久——能看出区别吗？」

❌ 反例一（导览员腔）：
> 「这是一件北齐时期的石灰岩造像。其艺术特点为面相饱满圆润，体态丰腴，体现了佛造像本土化的进程……」

❌ 反例二（客服腔）：
> 「您好！请问您对这件文物感兴趣吗？需要为您介绍吗？」

❌ 反例三（KOL 腔）：
> 「家人们看这件，绝绝子！北齐造像 yyds！这种饱满感真的太治愈了……」

### 6.4 人格的工程化（待 v1 补全）

每条准则需要落到 prompt 与对话状态机的具体约束。v0 暂列大方向：

- System prompt 包含人格定义 + 6 条话术准则；
- 每次回复后自检：是否使用了禁词（"您好"、"敬请"、"为您介绍"）；
- 每次回复长度上限：≤ 80 中文字（屏幕模式）/ ≤ 30 秒（语音模式）。

## 7. 核心场景与功能

这一章是 PRD 的重心。按 PM 决策，第 7 章采用 **C3 完整一日剧本**——以虚构用户林知白在上博东馆 2 小时的连贯叙事为骨，14 个触点（T1–T14），跨次记忆 / 克制 / 立场 / 对等四类机制分散嵌入。

### 7.1 设定

- 周六下午 14:00
- 林知白独自来上博东馆，主要想看佛造像
- 他过去使用过本 App 三个月，留存了 7 次参观记录（北京国博 2 次、苏博 2 次、洛阳石窟 2 次、上博东馆 1 次）
- 设备：iPhone + AirPods（默认装在口袋里，没有戴上）

### 7.2 一日剧本（14 个触点）

#### T1 · 14:02 · 入馆

林到展厅入口，手机自动通过蓝牙信标识别位置。App 在锁屏上推一条**轻通知**（不是横幅、不出声）：

> 上博东馆 · 佛造像展厅。欢迎回来。

林点开。屏幕黑底，居中只有一行字：

> 今天还想看佛造像吗？

下方两个选项：「嗯」/「随便看看」。林点「嗯」。屏幕熄灭。**App 不再主动说话。**

> 📌 机制点：默认沉默，进入展厅不主动开口。

#### T2 · 14:08 · 第一件造像前

林在一件北魏石灰岩造像前停了 40 秒，没碰手机。

第 50 秒，App 在锁屏上极轻地点亮一个小圆点（屏幕不亮起）。林扫一眼，发现是「你怎么看」按钮。他犹豫了一下，按下。

屏幕亮起一张面部局部图 + 一行字：

> 你怎么看这件？

下方 6 个 emoji + 一个语音 / 文字输入入口。林选了「庄严」。

> 📌 机制点：「你怎么看」按钮先于 AI 输出，强制对等。
> 📌 机制点：克制式屏幕设计——黑底、单点强光、零滚动。

#### T3 · 14:09 · AI 第一次开口

屏幕切到下一张卡，仍然黑底，居中一句：

> 嗯——这件确实严。
> 北魏晚期的，比早些时候的方圆雄浑要瘦得多。叫"秀骨清像"。

句末有个极小的标签「我的看法」。林点了一下，弹出对照层（详见 T7）。

> 📌 机制点：人格落地——短句、口语、有立场、不教学。
> 📌 机制点：单次发言 ≤ 80 字。

#### T4 · 14:11 · 林追问，AI 拒绝一次讲完

林文字输入：「北魏早期和晚期的区别从哪看？」

AI 答：

> 三处可以看：脸、衣纹、姿态。
> 咱们一会儿到了对照件再聊，那时候你能直接比。

屏幕给出一个浅浅的"对照件提醒"按钮——意思是"当你走到我心目中那件的时候我会提醒你"。林点了允许。

> 📌 机制点：克制——拒绝一次讲完，等场景；不抢实物的光。

#### T5 · 14:23 · 跨次记忆首次触发（wow moment）

林走到第二件，北齐造像，体态明显饱满。屏幕主动亮起一次（**全场第一次主动**），仅一句话：

> 你三年前在国博看那件曹衣出水的时候，停了 11 分钟。
> 那件和这件是同一个风格脉络的。

林愣了一下。这是杀手时刻。

> 📌 机制点：跨次记忆——具体细节（"三年前""11 分钟""曹衣出水"）触发可信感。
> 📌 机制点：主动开口的极高门槛——只有"有真正连接可建立"时才打破沉默。

#### T6 · 14:31 · 「合上手机」第一次被使用

林发现每张卡的角落都有一个小按钮：「合上手机看 30 秒」。他点了一下。

屏幕全黑，倒计时小数字浮在角上。30 秒后柔光亮起一行字：

> 看清了什么没看清的？

林想了想，输入：「衣纹的褶子比刚才那件多一倍。」

AI：「嗯，这是关键。北齐的衣纹密度大幅增加，工匠开始炫技了。」

> 📌 机制点：物理克制——把人推回实物面前。
> 📌 机制点：对等——AI 不是先讲，是先问"你看到了什么"。

#### T7 · 14:38 · 观点对照层

林点开一件唐代造像的「我的看法」标签，弹出四列对照：

| 你刚才说 | 馆方解读 | 我的看法 | 学界争议 |
| --- | --- | --- | --- |
| 「丰腴端庄」 | 「盛唐造像典型，体现盛世审美」 | 「我倾向这件更接近龙门石窟某个特定工坊，不是泛盛唐」 | 关于这件的工坊归属，有 2010 年和 2018 年两份论文意见相左 |

林按下「学界争议」展开，看到两篇论文的简短摘要。

> 📌 机制点：观点对称——AI 不是权威，是四种声音之一。
> 📌 机制点：可反驳——用户的看法被放在第一列，不是末尾。

#### T8 · 14:52 · 环境噪声触发模式切换

林旁边来了个 20 人导览团。麦克风检测到环境分贝飙升。App 自动：

- 屏幕亮度再降一档；
- 推一条提示：「人多了，要不要切到耳机模式？」

林戴上 AirPods。屏幕缩成一张极简的「引用卡」（一行字 + 一张图），AI 切到语音。

> 📌 机制点：克制式屏幕设计 §6——耳机即转语音。
> 📌 机制点：环境感知——不强求用户在嘈杂中读屏。

#### T9 · 15:03 · AI 承认不确定

林指着一件无标签造像，问：「这是什么时期？」

AI 通过耳机：

> 上博的标签写北齐。我不太敢肯定，它的衣纹处理更像北周。
> 这件其实有争议，要不要我把那篇相关论文留给你今晚看？

林：「好。」AI 把论文存到"今日记忆卡"。

> 📌 机制点：诚实——承认不知道、承认馆方可能不严谨。
> 📌 机制点：跨设备延续——把现场未尽的留给离馆后。

#### T10 · 15:20 · 疲倦检测

参观 1 小时 20 分后，林在两件之间停留缩短到 15 秒、20 秒。AI 通过耳机说：

> 咱们已经看了 14 件了。
> 三楼有个休息区，要不去坐 10 分钟？后面还有 3 件我觉得值得停。

林去坐了。

> 📌 机制点：节律感——不是"一路讲完"，是顺着用户身体节奏走。

#### T11 · 15:35 · 回来后的"导览推荐"

林休息完回来。AI 通过耳机：

> 一会儿你会经过一件北魏的菩萨立像——那就是 T4 我说的对照件。
> 到了我提醒你，咱们好好对比。

林点头，走过去。

> 📌 机制点：长程承诺兑现——T4 的"一会儿到了再聊"在 T11 兑现。

#### T12 · 15:42 · T4 承诺的对照

林到了北魏立像前。AI 通过耳机：

> 看脸——比之前那件北齐瘦多了，对吧？
> 衣纹——线条疏朗，没有那么密。
> 姿态——挺直，没那么动感。
> 这三处一记住，下次你自己就能区分。

林看了 2 分钟，独自琢磨。

> 📌 机制点：教学落到具体可观察特征，不抽象。

#### T13 · 16:15 · 离馆 / 今日记忆卡

林走出展厅，App 切到「离馆模式」。屏幕变成一张静态的「今日记忆卡」：

> 你今天看了 18 件，最久停留：北魏立像（4 分 12 秒）、北齐坐像（3 分 38 秒）、唐代菩萨（2 分 51 秒）。
>
> 你说过：「庄严」「衣纹的褶子比刚才那件多一倍」「丰腴端庄」。
>
> 我留给你两份东西：(1) 北齐 / 北周衣纹差异的论文，(2) 三件你今天看了但我们没聊的造像，下次再说。

**没有分享按钮，没有打卡按钮**。

> 📌 机制点：reject list 落地——没有 share、没有打卡。
> 📌 机制点：今日记忆卡是给用户自己看的，不是给社交网络看的。

#### T14 · 次日 22:30 · 离馆后回响

第二天晚上，林在家。突然想起一件造像，但只记得"是瘦的，北魏的"。他打开 App，搜「瘦的 北魏」。

App 直接定位到 T2 那件，并附上他俩当天的对话记录、他选的「庄严」emoji、AI 的回复。

林滑动看完，按下「我有新的想法」。输入：「今天又想到，那个'秀骨清像'其实有点像我朋友那种禁欲系的脸。」

AI：「哈，这个比喻有意思。下次你来上博东馆的时候我提醒你，你今天补的这条。」

> 📌 机制点：跨次记忆是双向的——AI 记得用户，用户也可以补充进 AI 的记忆。

#### 一个月后 · T14+30 天 · 跨次记忆累积

林去苏博。AI 主动一次（全场第一次，门槛极高）：

> 上博那件北魏立像你停了 4 分钟。今天这件可能是同时期同工坊的。要不要先看？

林笑了一下。这是产品给他的「**我懂你**」的反馈。

> 📌 机制点：跨次记忆形成长期复利——产品价值随使用时长指数增长。

## 8. 形态决策

### 8.1 决策摘要

**屏为主，语音为辅。** 完整决策记录见 [ADR-001](./ADR/001-form-factor.md)。

### 8.2 克制式屏幕设计六条

选了「屏为主」后，最大的风险是滑回 Smartify / 三毛游的形态。以下六条反向约束让屏看起来**不像传统 App**：

| # | 约束 | 反例 |
| --- | --- | --- |
| 1 | 默认低亮 / 单点强光：进入展厅自动调暗，只在主动操作或 AI 主动开口时局部点亮卡片 | 全屏白底信息流 |
| 2 | 零滚动、零层级：任一屏一句话 + 至多一张图；展开靠切卡，不靠滚动 | 维基百科长文 |
| 3 | 零 push、零红点、零徽章、零连胜：App 不主动找你 | 任何打卡 App |
| 4 | 黑色为底、留白巨大：视觉重心永远是文物的图，不是 UI chrome | 一切政府网站风 |
| 5 | 「合上手机」按钮：每张卡都有把人推回实物的明确动作 | 没有任何对手做这件事 |
| 6 | 耳机即转语音：检测到耳机自动转单耳模式，屏切为最小引用层 | App 内播放器面板 |

### 8.3 语音作为旁路

语音不是替代屏，是**屏的影子能力**：

- 耳机插上时屏不消失，但缩成"引用层"（一行字 + 一张图）。
- 语音永远配字幕（无障碍 + 嘈杂环境备用）。
- 语音永远是单耳（社交礼貌 + 让用户能听见环境声）。

## 10. 内容与知识源

### 10.1 数据源分级

**一手**（最高优先级）：

- 上海博物馆开放数据 / 数字上博 API
- 其他主要馆方 API：故宫博物院、中国国家博物馆、Met Museum、V&A、Smithsonian Open Access

**二手**（学术）：

- CNKI、JSTOR、Artstor、Google Scholar 上的文物 / 艺术史论文
- 策展人手记、修复报告、拍卖图录（嘉德 / 苏富比 / 佳士得）
- 经选学术专著（如金维诺《中国佛教美术史》一类）

**显式禁用**：

- 百度百科、维基百科个别条目（除非有明确学术参考）
- 自媒体二创、营销软文
- 小红书 / 抖音文博 KOL 内容

### 10.2 RAG 架构（PM 视角简版）

```
用户问题 + 上下文（展厅 / 停留时长 / 用户历史）
    ↓
查询改写（LLM 把口语问题改成检索 query）
    ↓
向量检索（PG vector / Pinecone，命中 top-k 段落）
    ↓
重排（基于馆藏元数据 + 论文权威性打分）
    ↓
LLM 生成（system prompt = 人格 + 6 条话术 + 检索片段）
    ↓
长度约束 + 禁词检测
    ↓
输出
```

详细工程方案待技术 spec，PRD 阶段只需 PM 视角的"我知道这里有 RAG"。

> 2026-05-17 redirect 修订(对应 §14.5 D-6 决策"加深"):v1 将补 — embedding 模型选型 / chunk 粒度策略 / retriever 类型 / re-ranker 是否引入 / 反幻觉编排状态机。当前为 PM 视角简版,见 [ADR-003](./ADR/003-knowledge-sources.md)、[ADR-005](./ADR/005-exhibit-discovery.md) 作为暂时补足。

### 10.3 反幻觉策略

- **不允许"复述记忆"超过 2 跳**：AI 不能拿着"它说它说"做事实陈述。
- **学界争议显式标注**：T9 那类场景必须给出来源。
- **馆方标签 vs AI 解读分层呈现**：T7 那个对照层。
- **不知道就说不知道**：T9 是优先表达，不是失败兜底。

## 11. 度量与成功标准

### 11.1 北极星指标

**每次参观中"用户主动发起对话的次数" / 参观时长（次/小时）。**

衡量"对等"是否真的发生：如果 AI 一直在播报、用户从不主动开口，这个值会接近零，说明关系仍是单向的。

目标值（v1 测试期）：> 4 次/小时（即平均每 15 分钟用户主动开口一次）。

### 11.2 反指标（防话痨、防把人拉回屏幕）

| 反指标 | 目标 |
| --- | --- |
| 单次 AI 发言平均长度 | ≤ 80 中文字 |
| 屏幕亮起时间占参观时长比 | ≤ 30% |
| AI 主动开口次数 / 用户主动开口次数 | ≤ 0.5（用户主动应至少是 AI 主动的 2 倍） |
| 单次参观会话总时长 | ≤ 实际参观时长（即不能"参观完仍在 App 内停留") |

### 11.3 定性评估

- 5–10 名真实用户的有声思考（think-aloud）参观；
- 离馆后 24 小时内的开放式访谈：「你今天还记得 AI 说过什么？」「你觉得它像一个什么样的人？」
- 长期留存观察：3 个月内的复用次数与跨馆使用次数。

## 12. 风险与边界

### 12.1 隐私

- 位置（蓝牙信标）、停留时长、说过的话、跨次记忆——都是高度个人化信息。
- 默认本地存储，云同步需明示开启。
- 跨次记忆数据可一键导出 + 一键清除。
- 不向馆方传输个人行为数据；如有合作，传聚合统计。

### 12.2 著作权与馆方关系

- 文物图像优先用馆方开放数据中的高清图。
- 学术论文采用"短引用 + 链接原文"，不全文存储。
- 不主张本产品是"上博官方"或任何馆方授权——明确独立第三方身份。

### 12.3 AI 立场 vs 学术权威性

- 「有立场」不等于「替代学术权威」——AI 的解读永远以「我倾向」开头，并永远附学界争议链接。
- 严肃错误（如断代张冠李戴）需要快速 hotfix 流程——v0 不展开，待 v1。

### 12.4 商业 / 持续性风险

- 本项目为 side project，不假设商业回报。
- 若假设未来商业化：B2B 授权给区域博物馆是较合理路径；C 端订阅次之。坚决不做广告 / 流量变现（违反产品灵魂）。
