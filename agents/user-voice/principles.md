# 目标用户的 4 条原则

> 这 4 条原则取代了"单一 persona = 目标用户"的旧模型。
> 来源:PM 2026-05-17 口述。User-Voice 维护,Builder 在 PRD §3.3 重构时引用此文件。
>
> 目标用户**已经认同**、或**将会在使用本产品后认同**以下原则。

## 原则 A:反对"博物馆 = 超市"式的浅层窥探

目标用户**极度反感**这样一种博物馆主题的视频/讲解风格:

> "逛博物馆就像逛超市。你只要看懂里面的'商品',看懂它的朝代、生产日期,通过这个窗口去感受古人的生活方式,就够了。"

这种叙事把展品降级为消费品式的奇观,把博物馆体验降级为"看懂朝代 + 想象古人"的浅层愉悦。我们的用户对此**直觉性地排斥**——他们说不出全部理由,但知道不对劲。

**产品含义**:同伴的语气不能滑向"哇这个朝代 X 真有意思 / 古人真聪明"。

## 原则 B:对照本宣科讲解员的直觉反感

目标用户**直觉性地不喜欢官方讲解员照本宣科式的导览**。

承认存在例外:有少数极具洞见的「大咖式讲解人」,能提供高质量观察、跨展品联结、立场性判断。但**绝大多数讲解员**只是在背诵关于藏品的客观描述——器物朝代、生产工艺、闲趣轶闻——而仅仅停留在这些描述。

> 这些信息是远远不够的。

**产品含义**:AI 同伴在默认状态下**不是讲解员**。它的开场不是"这件是 X 朝的 Y,采用了 Z 工艺",而更像一个朋友的提问或观察。讲解员模式可以存在,但作为可选的"工具档",不是默认人格。

## 原则 C:觉察博物馆叙事背后的权力结构

目标用户**已经发现**——或者将在使用本产品后**认同**——博物馆本身就是一种**叙事**;而**叙事一定与权力结构相绑定**。

对他们而言,有益的是:**觉察**博物馆隐身的叙事视角、叙事结构、以及它们背后的权力结构。

**尤其是**:中国大陆这样极权体制下的社会视角中,博物馆作为权力机器一部分的叙事运作。

**产品含义**:
- 同伴可以、也应当指出"这块说明牌为什么这样写、不写另一种"
- 同伴可以引用海外学术视角与馆方官方叙事的张力
- 同伴**不**承担政治宣传的相反角色——它只是诚实地把叙事性、视角性、权力性这一层 surface 出来
- 这条原则直接连接 PRD §6 人格的"承认不确定 / 多视角对照"
- **风险**:此原则涉及 PRD §12 边界中"AI 立场 vs 学术权威性"的张力,在大陆运营存在合规风险——这是产品**必须诚实面对**的边界,不是要回避的话题

## 原则 D:目的是阅读知识结构的网络,而非消遣

目标用户**已经认同**或将会认同:逛博物馆的目的**可以**是消遣的,但**更高价值的目的**应当是——

> 读懂现实器物背后所蕴含的**知识结构**。

这个"知识结构"包括至少四层:

1. **布展者意图的知识结构**:策展人/馆方意图传达什么叙事
2. **用户自我认同的知识结构**:用户自身对这一领域已有的结构性认知
3. **结构性批判**:对布展者意图的反思与挑战
4. **跨展览/跨馆的网络连接**:不同展览、不同馆之间传达的知识结构如何互相印证、冲突、互补

**产品含义**:
- 同伴的核心交付物**不是单件展品的更多信息**,而是**展品之间的关系**、**叙事之间的对照**
- PRD §7 中的"观点对照层"(T7)、"跨次记忆触发"(T5)直接对应这一原则
- 北极星指标应当能捕捉"用户读懂了关系网"而非"用户消费了多少展品信息"
- 衡量"高质量交互"的标准不是停留时长,而是是否触发了用户原本不会有的结构性认知

---

## 这 4 条原则的相互关系

```
A 反对超市叙事 ────┐
                  ├─→ 都通向 D:目的是知识结构,不是消遣式窥探
B 反对照本讲解 ────┘
                       ↑
C 觉察权力结构  ───────┘
(为 D 提供一个具体的、不可绕开的"知识结构"维度)
```

D 是终点。A、B、C 是 D 的三个前置必要条件——只有同时认同 A+B+C 的用户,才有可能完整认同 D。

---

## 如何使用

- **Builder** 写 PRD §3.3 时,把这 4 条概括进去,引用本文件
- **User-Voice** 做旁评时,逐条对照
- **PM-Critic** review 时,把"违反 A/B/C/D 任一条"列为 T2 升级候选
- **Strategy-Curator** 做选品/数据相关性时,问"这件展品是否能承载 C 或 D?"

## 维护

- PM 可随时口述补充第 5、第 6 条原则——直接编辑此文件
- 任何原则被打破/修改 → 自动触发 User-Voice 对全部 instances.md 与 PRD §3.3 的复审
