## 选品标准(Curator 自检 checklist)

- [ ] 该展品具有「叙事张力」(适合 AI 同伴展开非琐碎对话)
- [ ] 至少存在 1 件可用的跨馆/跨展览对照件
- [ ] 现有数据(Met / 故宫 / 上博等)中有可用底材,或可在合理成本内补
- [ ] 不与 PRD §9 Reject List 冲突(典型:不选纯娱乐化展品)
- [ ] 与 PRD §6 AI 人格契合(同行的资深爱好者,而非讲解员)
